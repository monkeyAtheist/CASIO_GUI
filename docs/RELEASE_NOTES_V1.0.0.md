# Release notes — CASIO GUI 1.0.0

CASIO GUI 1.0.0 is the first frozen public release of the GRAPH 90+E GUI
framework.

The release is based on the physically validated Phase 21 runtime.

Validated areas include:

- full controls catalogue;
- shapes and retained Canvas;
- Graph, Table, Tree and structured controls;
- Panel, Container, ScrollView, Grid/layouts and TabView;
- image controls with fxconv assets;
- Light, Dark and High Contrast theme propagation;
- focus routing including nested controls;
- TextBox mixed/text-only/numeric-only input;
- ColorWheel/Numeric/LED bidirectional interaction;
- popup controls;
- safe persistence;
- BMP screenshots;
- correct filesystem world-switch handling.

No runtime behavior is intentionally changed by the v1 freeze itself. The final
release adds semantic-version metadata, API documentation and freeze checking.
