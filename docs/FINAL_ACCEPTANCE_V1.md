# Final acceptance — v1.0.0

Physical GRAPH 90+E acceptance was completed before this API freeze.

Accepted runtime areas:

- Controls page, including TextBox modifiers and MenuBar focus.
- Shapes/Canvas page.
- Data page, including Tree/List/Combo keyboard selection.
- Meter page, themes and ColorWheel/Numeric/LED linkage.
- Layout page, nested focus rules, ScrollView behavior, image controls and Canvas.
- System/popups/persistence tests.
- Safe file access using `gint_world_switch()`.
- Screenshot capture to `/Capt/image.bmp` without reboot.
- Light, Dark and High Contrast theme behavior.

The v1.0.0 freeze does not intentionally modify the validated runtime logic.
It freezes and documents that baseline.
